# Backend watsonx — origem e status

Este diretório contém o backend Node.js/Express originalmente publicado em
`Vladihersen/mentoria-leveza`, com as correções de bugs aplicadas.

Ele foi copiado para cá porque o repositório `mentoria-leveza` está **arquivado**
no GitHub e recusa push (HTTP 403, somente leitura). Para devolver o código ao
repositório de origem, é preciso desarquivá-lo em
Settings → General → Danger Zone → Unarchive.

Este backend é a API IBM watsonx.ai. Ele **não** é o Cloudflare Worker publicado
em `levezadeviver-oficial.vladihersen.workers.dev` — o código-fonte desse Worker
não está em nenhum repositório do GitHub desta conta.
